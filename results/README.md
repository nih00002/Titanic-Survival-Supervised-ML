# Results

This folder contains selected results extracted from the original 2020 Titanic supervised machine-learning group project.

These figures are historical artifacts from the original project and are not newly generated outputs from the reconstructed portfolio notebook.

Included results cover:

- passenger survival analysis
- survival patterns across passenger features
- fare and passenger-class analysis
- model evaluation
- Decision Tree feature importance
- Decision Tree visualization
- example passenger prediction and Kaggle submission output

The reconstructed notebook may produce different numerical results because the surviving 2020 report and code export contain slightly different experimental settings.
