# Notebook

`Titanic_Survival_Classification_Reconstructed.ipynb`

This notebook reconstructs the original WS 2019/2020 supervised machine-learning workflow from the surviving code-export PDF and final group report.

It includes:

- exploratory analysis
- data cleaning
- categorical encoding
- KNN
- Decision Tree
- Random Forest
- accuracy, precision, recall, and confusion matrices
- feature importance
- decision-tree visualization
- passenger-level prediction
- Kaggle test-set prediction generation

Historical report results and code-export results are documented separately inside the notebook because they came from slightly different experiment versions.
